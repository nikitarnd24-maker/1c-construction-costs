# 1C:Extension — Управление затратами в строительстве и недвижимости

Базовая конфигурация: 1С:Бухгалтерия предприятия, редакция 3.0 (БП 3.0)
Платформа: 1С:Предприятие 8.3
Технология: Расширение конфигурации (.cfe)


## Описание проекта

Расширение для автоматизации учета в строительстве и недвижимости. Реализует распределение затрат по объектам и оптимизацию складского документооборота без изменения типовой конфигурации.


## Структура расширения

Расширение/
├── Документы/
│   └── ПоступлениеТоваровУслуг/
│       ├── Реквизиты: itnНоменклатура, itnСумма, itnКоличествоНоменклатуры,
│       │             itnСчетЗатрат, itnСтатьяЗатрат, itnПодразделение
│       ├── Табличная часть: itnДома (Дом, Площадь, Использовать)
│       └── Обработчик: itnРаспределитьПосле
├── Справочники/
│   └── НоменклатурныеГруппы — доп. реквизиты для аналитики
└── Печатные формы/
    └── ТребованиеНакладнаяМ11 — переработанный макет


## Ключевой функционал

1. Распределение затрат пропорционально площади объектов. Округление до 2 знаков, последний объект получает остаток суммы.

2. Кастомизация документа «Поступление товаров и услуг»:
   - раздел «Услуги» — под приемку СМР
   - раздел «Товары» — ускорение ввода

3. Складской учет:
   - доработка формы «Требование-накладная»
   - переработанная печатная форма М-11

4. Справочник «Номенклатурные группы» — доп. аналитика для разделения затрат


## Техническая реализация

- Добавление реквизитов и табличных частей через расширение
- Обработчики &НаКлиенте / &НаСервере
- Автоматическое заполнение субконто (до 3 уровней) в зависимости от настроек счета
- Валидация перед распределением: суммы, количества, заполнение таблицы домов
- Динамическое обновление формы после распределения


## Установка и настройка

### Для разработки (из исходников)

1. Клонировать репозиторий  
2. В конфигураторе создать новое расширение  
3. Выполнить **Сравнение, объединение с расширением** → загрузить изменения из каталога  
4. Установить приоритет расширения (рекомендуется 10–20)  
5. При необходимости: **Конфигурация → Поддержка → Обновить конфигурацию расширения**

### Для конечного использования (из .cfe)

1. Загрузить `.cfe` через **Администрирование → Расширения конфигурации**  
2. Установить приоритет



## Особенности

- Не требует изменения типовой конфигурации
- Сохраняет работоспособность при обновлении БП 3.0
- Рекомендуемая платформа: 8.3.10+
